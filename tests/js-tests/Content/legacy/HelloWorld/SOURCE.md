# Reference source

`main.js`, `project.json`, `src/` and `res/` were copied without modifications from
`cocos2d-x/templates/js-template-default` at commit
`e4b6a5ef8f` on the reference repository's `v3` branch. The original MIT copyright
and permission notices remain in the JavaScript sources.

The Axmol test harness adds this directory to the resource search path and runs
the original entry script. Assertions live separately in `src/LegacySmoke.js`
under the Axmol test Content directory.
